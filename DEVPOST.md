## Tagline

Know where your money goes, with AI-assisted expense categorisation and transparent spending statistics.

## Inspiration

Tracking expenses is most useful when recording a transaction is quick and monthly totals are easy to understand. SpendWise AI brings expense entry, owner-scoped data, and AI-assisted categorisation into one focused workflow.

## What it does

- Provides Supabase email/password authentication.
- Stores expenses in PostgreSQL with owner-only row-level security.
- Supports creating, reading, editing, deleting, searching, and filtering expenses.
- Calculates dashboard totals and chart inputs deterministically from saved transactions.
- Suggests expense categories using the AI Lodge apiyi OpenAI-compatible API when configured, with a clearly labelled deterministic fallback.
- Includes an Insights page with deterministic monthly statistics. AI-generated spending insights are currently paused because successful live provider behavior has not been verified.

## How it was built

SpendWise AI uses Next.js, React, TypeScript, Supabase Auth/Postgres/RLS, and the AI Lodge apiyi OpenAI-compatible API. Provider calls are made by server routes. Categorisation input and model responses are validated. Dashboard and Insights-page statistics are calculated from stored expense records rather than generated by AI.

## Challenges

Separating a recovery session from ordinary sign-in, protecting each expense at both the API and database layers, and keeping financial totals deterministic while using a language model only for qualitative observations.
